# 404.Rst

## Overview
This is the **not-found fallback page** for Godot's Read the Docs documentation site. It provides user-facing messaging for broken links and implements **client-side redirect logic** to route users to the correct documentation pages. The page handles two scenarios: RTD language selector misroutes (`/en/4.x/`) and bulk page redirects managed via a CSV file.

## Key Patterns

### Pattern 1: RTD Language Selector Fix
Read the Docs' language selector can redirect English-language users to a non-existent `/en/4.x/` branch. The fix detects this and redirects to `/en/stable/`.

```javascript
if (window.location.pathname.includes('/en/4.x/')) {
  const newUrl = window.location.pathname.replace('/en/4.x/', '/en/stable/');
  window.location.replace(newUrl);
}
```

### Pattern 2: CSV-Driven Bulk Redirects
Redirects are managed in a static `redirects.csv` file rather than configured server-side, to bypass Read the Docs' limit on configurable redirects.

```javascript
fetch(currentBasePath + "/_static/redirects.csv")
  .then(response => response.text())
  .then(csvText => {
    const lines = csvText.trim().split('\n');
    for (const line of lines) {
      const [from, to] = line.split(',').map(s => s.trim());
      if (from && to) {
        if (window.location.pathname.endsWith(from)) {
          if (to.startsWith('https://')) {
            window.location.replace(to);
          } else {
            const newUrl = window.location.href.replace(
              window.location.pathname, currentBasePath + to
            );
            window.location.replace(newUrl);
          }
        }
      }
    }
  });
```

- CSV format: `from_path, to_path` (relative or absolute URL).
- Supports both internal (relative) and external (`https://`) redirect targets.

### Pattern 3: Base Path Extraction
Handles multi-language RTD URL structures like `/en/stable/` by extracting the first two path segments.

```javascript
const currentPathSegments = window.location.pathname.split('/').filter(segment => segment !== '');
const currentBasePath = (currentPathSegments.length >= 2)
  ? ("/" + currentPathSegments.slice(0, 2).join("/"))
  : "";
```

## API Reference
| Signature | Description |
|---|---|
| `window.location.replace(url)` | Redirects without adding to browser history |
| `fetch(url).then(cb)` | Retrieves the redirect CSV asynchronously |
| `currentBasePath` | Computed prefix like `/en/stable` for constructing valid URLs |

## Gotchas
- **`4.x` is not a real branch for English docs.** It exists only for non-English translations (single branch covering all 4.x versions). English uses `stable`.
- **Redirect limit bypass:** Read the Docs caps server-side redirects, so bulk renames must be handled client-side via CSV.
- **`window.location.replace` vs `window.location.href`:** `.replace()` is used intentionally to avoid polluting browser history with broken URLs.

### Jinn Heuristics
- **HEURISTIC:** When hosting platforms impose limits on server-side redirects, use a static CSV + client-side JS as a scalable alternative. — *source: Godot RTD setup*
- **HEURISTIC:** Always use `window.location.replace()` for corrective redirects so broken links don't linger in the user's back-button history. — *source: Godot*
- **HEURISTIC:** Distinguish between `latest` (development) and `stable` (release) documentation; broken links often result from version mismatches. — *source: Godot*
